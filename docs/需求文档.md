# 东南大学招聘信息系统 — 需求文档

> 版本：v1.2  
> 日期：2026-09-05  
> 状态：修订稿

---

## 1. 项目概述

### 1.1 项目名称
东南大学招聘信息系统（SEU Job）

### 1.2 项目目标
搭建一个面向东南大学学生的招聘信息展示网站，以卡片形式聚合展示企业招聘信息（文本、图片、微信推送链接），支持管理员便捷编辑，使用 MySQL 存储数据。

### 1.3 项目范围
- 访客端：直接浏览卡片 → 查看详情（无需登录）
- 管理端：账号密码登录 → 增删改岗位信息
- 数据存储：MySQL 数据库
- 内容形式：文本描述、多张图片、微信推送链接、HR联系方式、投递联系图片

### 1.4 目标用户
- **访客：** 东南大学在校学生（直接访问，无需登录）
- **管理员：** 项目维护者（独立账号密码登录）

## 2. 功能需求

### 2.1 访客端（公开访问）

访客端无需登录，直接访问主页浏览招聘信息卡片，点击查看详情。

**交互流程：**
```
访问网站 → 直接进入主页（卡片列表） → 点击卡片 → 查看详情
```

### 2.2 招聘信息展示模块（访客端主页）

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F-010 | 卡片列表 | 以卡片形式展示所有招聘岗位，按时间倒序排列，新增记录自动排在最前 | P0 |
| F-011 | 卡片信息 | 每张卡片展示：标题、公司、摘要、内容类型标识 | P0 |
| F-012 | 详情页 | 点击卡片进入详情页，展示完整文本/图片/链接 | P0 |
| F-013 | 返回列表 | 详情页提供返回按钮，回到卡片列表 | P0 |
| F-014 | 搜索/筛选 | 支持按关键词搜索或按分类筛选（可选） | P2 |
| F-015 | 响应式布局 | 页面适配手机和桌面端 | P1 |

**卡片数据结构：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键，自增 |
| title | VARCHAR(200) | 招聘标题（如"XX公司2026校招"） |
| company | VARCHAR(100) | 公司名称 |
| summary | VARCHAR(500) | 卡片摘要（列表页显示） |
| content_text | TEXT | 文本内容（可选） |
| content_image | TEXT | 图片 URL，支持多图 JSON 数组格式（可选） |
| content_link | TEXT | 链接 URL（可选，如微信推送链接） |
| hr_contact | VARCHAR(500) | HR 联系方式（可选） |
| contact_image | VARCHAR(500) | 投递相关联系图片链接（可选） |
| tags | VARCHAR(200) | 标签，逗号分隔（如"校招,实习,计算机"） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| is_active | BOOLEAN | 是否上架（默认 true） |

> **说明：**
> - 每条招聘信息可以同时包含文本、图片、链接三种内容，无需分类。
> - `content_image` 支持多图，存储格式为 JSON 数组，如 `["/uploads/a.jpg", "/uploads/b.jpg"]`，兼容旧数据单 URL 格式。

### 2.3 管理员模块

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F-020 | 管理入口 | 主页提供管理入口（如导航栏"管理"按钮或 `/admin` 路由） | P0 |
| F-021 | 管理员登录 | 输入管理员账号和密码，验证通过后进入管理模式 | P0 |
| F-022 | 新增招聘信息 | 表单填写信息，支持选择内容类型（文本/图片/链接），提交后新增卡片 | P0 |
| F-023 | 编辑招聘信息 | 点击卡片的编辑按钮，弹出编辑表单，修改后保存 | P0 |
| F-024 | 删除招聘信息 | 删除某张卡片（需二次确认） | P0 |
| F-025 | 上架/下架 | 控制招聘信息是否在访客端显示，不删除数据 | P1 |
| F-026 | 管理状态切换 | 管理员登录后卡片显示编辑/删除按钮；退出后恢复普通视图 | P0 |

**管理端表单字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 标题 | 文本 | ✅ | 如"XX公司2026校园招聘" |
| 公司名称 | 文本 | ✅ | 如"华为技术有限公司" |
| 摘要 | 文本 | ✅ | 卡片上显示的简短描述 |
| 文本内容 | 长文本 | ❌ | 招聘文本信息（可选） |
| 图片 | 多图管理 | ❌ | 支持多张图片，可添加/删除/独立上传（可选） |
| 链接 URL | 文本 | ❌ | 微信推送链接等（可选） |
| HR 联系方式 | 文本 | ❌ | HR 的手机号/微信/邮箱等（可选） |
| 投递联系图片 | 图片上传 | ❌ | 投递相关联系图片，如二维码等（可选） |
| 标签 | 文本 | ❌ | 逗号分隔，如"校招,实习,Java" |

> **说明：**
> - 三种内容字段可同时填写，每条招聘信息可包含任意组合。
> - 图片支持多张，以 JSON 数组格式存储。

## 3. 非功能需求

### 3.1 安全性

| 编号 | 需求 | 描述 |
|------|------|------|
| NF-001 | 密码存储 | 管理员密码不硬编码前端，存储在后端数据库中（bcrypt 哈希） |
| NF-002 | 公开访问 | 访客端无需登录，直接浏览招聘信息 |
| NF-003 | Session 安全 | 管理员 Session 设置合理过期时间（如 2 小时） |
| NF-004 | 输入校验 | 前后端均做输入校验，防止 XSS 注入 |
| NF-005 | 权限隔离 | 访客只能浏览，管理员才能增删改 |

### 3.2 性能

| 编号 | 需求 | 描述 |
|------|------|------|
| NF-010 | 页面加载 | 首页加载时间 < 2 秒 |
| NF-011 | 数据量支持 | 支持同时展示 200+ 岗位卡片 |
| NF-012 | 图片上传 | 支持上传图片，最大 50MB，格式限 jpg/png/gif/webp |

### 3.3 可维护性

| 编号 | 需求 | 描述 |
|------|------|------|
| NF-020 | 数据备份 | 支持 MySQL 数据库导出备份 |
| NF-021 | 代码结构 | 前后端代码分离，目录结构清晰 |
| NF-022 | 配置外置 | 密码、端口、数据库连接等配置项外置 |

### 3.4 兼容性

| 编号 | 需求 | 描述 |
|------|------|------|
| NF-030 | 浏览器 | 支持 Chrome、Edge、Firefox、Safari 最新版本 |
| NF-031 | 设备 | 支持 PC 端和移动端访问 |

### 4.2 页面路由

| 路由 | 方法 | 描述 | 权限 |

| `/login` | GET | 管理员登录页面 | 公开 |

| `/api/jobs/:id/toggle` | PATCH | 上架/下架切换 | 需管理权限 |

## 5. 数据库设计

### 5.1 数据库名
`seu_job`

### 5.2 jobs 表结构

```sql
CREATE TABLE jobs (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  title         VARCHAR(200)   NOT NULL COMMENT '招聘标题',
  company       VARCHAR(100)   NOT NULL DEFAULT '' COMMENT '公司名称',
  summary       VARCHAR(500)   NOT NULL DEFAULT '' COMMENT '卡片摘要',
  content_type  ENUM('text', 'image', 'link') NULL DEFAULT NULL COMMENT '内容类型（已废弃）',
  content_text  TEXT           NULL COMMENT '文本内容',
  content_image TEXT           NULL COMMENT '图片URL（支持多图，JSON数组格式）',
  content_link  VARCHAR(500)   NULL COMMENT '链接URL（如微信推送）',
  tags          VARCHAR(200)   NULL COMMENT '标签，逗号分隔',
  hr_contact    VARCHAR(500)   NULL COMMENT 'HR联系方式',
  contact_image VARCHAR(500)   NULL COMMENT '投递相关联系图片链接',
  sender_name   VARCHAR(100)   NULL COMMENT '发布者姓名',
  sender_id     VARCHAR(50)    NULL COMMENT '发布者ID',
  original_time DATETIME       NULL COMMENT '原始发布时间（新增时自动设为当前时间）',
  is_active     BOOLEAN        NOT NULL DEFAULT TRUE COMMENT '是否上架',
  created_at    DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 5.3 admins 表结构

```sql
CREATE TABLE admins (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  username      VARCHAR(50)    NOT NULL UNIQUE COMMENT '管理员账号',
  password_hash VARCHAR(255)   NOT NULL COMMENT '密码哈希',
  created_at    DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 6. UI 设计要求

### 6.1 登录页（管理员专用）
- 简洁居中布局，带东南大学/招聘信息相关标题
- 管理员账号 + 密码输入框 + 登录按钮
- 错误提示区域
- 返回首页链接

### 6.2 主页（卡片列表）
- 顶部：标题栏 + 管理登录链接（管理员已登录时显示管理后台+退出按钮）
- 主体：卡片网格布局（响应式：PC 3 列，平板 2 列，手机 1 列）
- 每张卡片：标题（大字）、公司名称、摘要、内容类型标签（📝文本 / 🖼图片 / 🔗链接 / 📞HR / 📩投递）

### 6.3 详情页
- 顶部：返回按钮 + 标题
- 内容区：
  - 文本：直接渲染文本内容
  - 图片：多图网格展示
  - 链接：展示链接 + 可点击跳转（微信推送）
  - HR 联系方式：展示联系方式
  - 投递联系图片：展示投递相关图片
- 底部：公司、标签、时间等元信息

### 6.4 管理端编辑
- 弹出模态框（Modal）形式
- 选择内容类型后，动态显示对应的输入区域（文本框 / 图片URL / 链接URL）
- 提交后即时更新卡片
