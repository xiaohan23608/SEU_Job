## 3. 数据库设计

### 3.1 现有数据库结构

数据库已创建：`seu_job`

#### jobs 表（招聘信息）

```sql
CREATE TABLE jobs (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    title           VARCHAR(200)    NOT NULL COMMENT '招聘标题',
    company         VARCHAR(100)    NOT NULL DEFAULT '' COMMENT '公司名称',
    summary         VARCHAR(500)    NOT NULL DEFAULT '' COMMENT '卡片摘要',
    content_type    ENUM('text', 'image', 'link') NULL DEFAULT NULL COMMENT '内容类型（已废弃，保留兼容）',
    content_text    TEXT            NULL COMMENT '文本内容',
    content_image   TEXT            NULL COMMENT '图片URL',
    content_link    TEXT            NULL COMMENT '链接URL',
    tags            VARCHAR(200)    NULL COMMENT '标签，逗号分隔',
    sender_name     VARCHAR(100)    NULL COMMENT '发布者姓名',
    sender_id       VARCHAR(50)     NULL COMMENT '发布者ID',
    original_time   DATETIME        NULL COMMENT '原始发布时间',
    is_active       BOOLEAN         NOT NULL DEFAULT TRUE COMMENT '是否上架',
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### admins 表（管理员）

```sql
CREATE TABLE admins (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    username        VARCHAR(50)     NOT NULL UNIQUE COMMENT '管理员账号',
    password_hash   VARCHAR(255)    NOT NULL COMMENT '密码哈希',
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 3.2 数据库索引设计

```sql
-- 提升查询性能的索引
CREATE INDEX idx_jobs_original_time ON jobs(original_time DESC);
CREATE INDEX idx_jobs_is_active ON jobs(is_active);
CREATE INDEX idx_jobs_sender_id ON jobs(sender_id);
```

### 7.2 认证中间件 (server/middleware/auth.js)

```javascript
// 访客认证
function requireGuest(req, res, next) {
    if (req.session && req.session.isLoggedIn) {
        return next();
    }
    return res.redirect('/login');
}

// 管理员认证
function requireAdmin(req, res, next) {
    if (req.session && req.session.isAdmin) {
        return next();
    }
    return res.status(403).json({ success: false, message: '无权限' });
}

module.exports = { requireGuest, requireAdmin };
```

## 8. 安全设计

### 8.1 认证流程

```
用户输入密码
      │
      ▼
后端验证密码
      │
  ┌───┴───┐
  │       │
正确    错误
  │       │
  ▼       ▼
创建    返回
Session  错误
  │
  ▼
设置 Cookie
  │
  ▼
重定向到主页
```

### 8.2 安全措施

| 措施 | 实现方式 |
|------|---------|
| 密码存储 | 管理员密码使用 bcrypt 加密存储 |
| Session 安全 | 设置 httpOnly、secure、maxAge |
| CSRF 防护 | 使用 csurf 中间件 |
| XSS 防护 | 输入过滤 + 输出转义 |
| SQL 注入 | 使用参数化查询 |
| 请求限制 | 使用 express-rate-limit 防止暴力破解 |

```env
# 服务配置
```

## 9. 部署方案

### 9.1 开发环境

```bash
# 安装依赖
npm install

# 初始化数据库
mysql -u root -p < docs/database_init.sql

# 导入初始数据
python data/import_to_mysql.py

# 启动开发服务器
npm run dev
```

### 9.2 生产环境

```bash
# 安装依赖
npm install --production

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 启动服务
npm start

# 或使用 PM2
pm2 start server/app.js --name seu-job
```

### 9.3 访问地址

| 环境 | 地址 |
|------|------|
| 开发 | http://localhost:3000 |
| 生产 | http://your-server-ip:3000 |
