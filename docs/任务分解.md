## 任务总览

| 阶段 | 名称 | 任务数 | 预计工时 |
|------|------|--------|---------|

## P1：项目初始化（预计 2h）

### T1.1 创建项目配置文件
- **任务：** 初始化 `package.json`，配置依赖包和脚本命令
- **依赖：** 无
- **产出：** `package.json`
- **预计：** 15min

### T1.2 安装依赖包
- **任务：** 安装 express、mysql2、ejs、express-session、dotenv、bcryptjs 等
- **依赖：** T1.1
- **产出：** `node_modules/`、`package-lock.json`
- **预计：** 15min

### T1.3 创建环境配置
- **任务：** 创建 `.env` 和 `.env.example`，配置数据库连接、Session 密钥等
- **依赖：** 无
- **产出：** `.env`、`.env.example`
- **预计：** 15min

### T1.4 创建数据库连接模块
- **任务：** 编写 `server/db.js`，创建 MySQL 连接池
- **依赖：** T1.3
- **产出：** `server/db.js`
- **预计：** 30min

### T1.5 创建 Express 应用入口
- **任务：** 编写 `server/app.js`，配置中间件、挂载路由、启动服务
- **依赖：** T1.2、T1.4
- **产出：** `server/app.js`
- **预计：** 45min

---

## P2：登录模块（预计 2.5h）

### T2.1 创建认证中间件
- **任务：** 编写 `server/middleware/auth.js`，实现 `requireGuest` 和 `requireAdmin`
- **依赖：** T1.5
- **产出：** `server/middleware/auth.js`
- **预计：** 30min

### T2.2 创建认证路由
- **任务：** 编写 `server/routes/auth.js`，实现登录、登出接口
- **依赖：** T2.1
- **产出：** `server/routes/auth.js`
- **预计：** 30min

### T2.3 创建登录页模板
- **任务：** 编写 `views/login.ejs`，包含密码输入框和提交按钮
- **依赖：** 无
- **产出：** `views/login.ejs`
- **预计：** 30min

### T2.4 创建登录页样式
- **任务：** 编写登录页 CSS 样式，居中布局、按钮样式
- **依赖：** T2.3
- **产出：** `public/css/style.css`（登录部分）
- **预计：** 30min

### T2.5 创建登录页交互逻辑
- **任务：** 编写 `public/js/login.js`，处理表单提交、错误提示
- **依赖：** T2.3
- **产出：** `public/js/login.js`
- **预计：** 30min

### T2.6 管理员登录功能
- **任务：** 在 `auth.js` 中添加管理员登录接口，支持账号密码验证
- **依赖：** T2.2
- **产出：** 管理员登录 API
- **预计：** 30min

---

## P3：主页卡片列表（预计 3h）

### T3.1 创建页面路由
- **任务：** 编写 `server/routes/pages.js`，处理主页渲染
- **依赖：** T2.1
- **产出：** `server/routes/pages.js`
- **预计：** 30min

### T3.2 创建 API 路由
- **任务：** 编写 `server/routes/api.js`，实现获取招聘信息列表接口
- **依赖：** T1.4
- **产出：** `server/routes/api.js`
- **预计：** 45min

### T3.3 创建主页模板
- **任务：** 编写 `views/index.ejs`，包含顶部导航、卡片容器、分页组件
- **依赖：** T3.1
- **产出：** `views/index.ejs`
- **预计：** 45min

### T3.4 创建卡片样式
- **任务：** 编写卡片 CSS 样式，网格布局、卡片阴影、类型标识
- **依赖：** T3.3
- **产出：** `public/css/style.css`（卡片部分）
- **预计：** 30min

### T3.5 创建主页交互逻辑
- **任务：** 编写 `public/js/app.js`，加载数据、渲染卡片、分页功能
- **依赖：** T3.2、T3.3
- **产出：** `public/js/app.js`
- **预计：** 45min

### T3.6 添加搜索和筛选
- **任务：** 实现按关键词搜索、按内容类型筛选功能
- **依赖：** T3.5
- **产出：** 搜索筛选功能
- **预计：** 30min

---

## P4：详情页（预计 2h）

### T4.1 创建详情页路由
- **任务：** 在 `server/routes/pages.js` 中添加详情页渲染
- **依赖：** T3.1
- **产出：** 详情页路由
- **预计：** 15min

### T4.2 创建详情页 API
- **任务：** 在 `server/routes/api.js` 中添加获取单条记录接口
- **依赖：** T3.2
- **产出：** 详情页 API
- **预计：** 15min

### T4.3 创建详情页模板
- **任务：** 编写 `views/detail.ejs`，根据内容类型渲染不同内容
- **依赖：** T4.1
- **产出：** `views/detail.ejs`
- **预计：** 45min

### T4.4 创建详情页交互逻辑
- **任务：** 编写 `public/js/detail.js`，加载数据、渲染内容、返回功能
- **依赖：** T4.2、T4.3
- **产出：** `public/js/detail.js`
- **预计：** 45min

## P5：管理端（预计 4h）

### T5.1 创建管理页路由
- **任务：** 在 `server/routes/pages.js` 中添加管理页渲染
- **依赖：** T2.1（requireAdmin）
- **产出：** 管理页路由
- **预计：** 15min

### T5.2 创建管理页模板
- **任务：** 编写 `views/admin.ejs`，包含表格、操作按钮、新增表单
- **依赖：** T5.1
- **产出：** `views/admin.ejs`
- **预计：** 1h

### T5.3 创建新增接口
- **任务：** 在 `server/routes/api.js` 中添加新增招聘信息接口
- **依赖：** T3.2
- **产出：** POST /api/jobs
- **预计：** 30min

### T5.4 创建编辑接口
- **任务：** 在 `server/routes/api.js` 中添加编辑招聘信息接口
- **依赖：** T3.2
- **产出：** PUT /api/jobs/:id
- **预计：** 30min

### T5.5 创建删除接口
- **任务：** 在 `server/routes/api.js` 中添加删除招聘信息接口
- **依赖：** T3.2
- **产出：** DELETE /api/jobs/:id
- **预计：** 20min

### T5.6 创建上下架接口
- **任务：** 在 `server/routes/api.js` 中添加上下架切换接口
- **依赖：** T3.2
- **产出：** PATCH /api/jobs/:id/toggle
- **预计：** 20min

### T5.7 创建管理页交互逻辑
- **任务：** 编写 `public/js/admin.js`，实现增删改查、上下架操作
- **依赖：** T5.2、T5.3-T5.6
- **产出：** `public/js/admin.js`
- **预计：** 1h

### T5.8 创建管理员账号
- **任务：** 编写脚本初始化管理员账号（bcrypt 加密密码）
- **依赖：** T1.4
- **产出：** 管理员初始化脚本
- **预计：** 20min

### T6.1 全局样式统一
- **任务：** 统一字体、颜色、间距等全局样式变量

- **产出：** CSS 变量定义
- **预计：** 30min

### T6.2 响应式适配
- **任务：** 添加媒体查询，适配手机、平板、桌面三种断点
- **依赖：** T3.4
- **产出：** 响应式 CSS
- **预计：** 45min

### T6.3 动画与交互效果
- **任务：** 添加卡片 hover 效果、页面过渡动画、加载状态
- **依赖：** T3.4
- **产出：** 动画 CSS + JS
- **预计：** 45min

### T6.4 暗色模式（可选）
- **任务：** 添加暗色主题支持，通过 CSS 变量切换
- **依赖：** T6.1
- **产出：** 暗色模式样式
- **预计：** 30min
